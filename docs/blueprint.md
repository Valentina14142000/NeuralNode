# **App Name**: NeuralNode

## Core Features:

- AI-Powered Proposal Tool: Uses AI to generate customized project proposals based on the job description and the freelancer's specific skills and past work history.
- Skill Verification Badges: Verifies AI expertise by analyzing GitHub repositories or via small, time-boxed technical assessments processed by LLMs.
- Real-time Bidding Dashboard: A dynamic interface for businesses and freelancers to manage active project bids and view current market rates.
- Secure Escrow with Stripe: A payment integration using Stripe Connect to hold project funds safely and release them only upon milestone completion.
- Matching Logic Database: Backend implementation using a modern database for managing the complex relationships between talent, clients, and contracts.
- Expert Profiles: Modular profiles showcasing specialized tech stacks such as Large Language Models, RAG implementations, and autonomous agents.
- Project Lifecycle Tracker: A visual timeline to monitor project progress from initial pitch through code review to final deployment.

## Style Guidelines:

- Primary color: Deep Amethyst (#7966E2) to reflect sophisticated technical innovation and intelligence.
- Background color: Deep Onyx (#1A1920) which is a desaturated version of the primary hue for a high-contrast dark mode feel.
- Accent color: Bright Azure (#367AF1) to highlight calls to action and important status updates.
- Headline font: 'Space Grotesk' for a computerized, scientific, and technical aesthetic. Body font: 'Inter' for objective and clear readability in long bid descriptions.
- Thin-stroke, geometric vector icons representing data nodes, neural pathways, and algorithmic connections.
- Modular dashboard layout utilizing CSS grid for a structured, command-center aesthetic inspired by high-end development environments.
- Micro-interactions including soft glow pulses for AI-processing states and sleek sliding transitions for menu components.
